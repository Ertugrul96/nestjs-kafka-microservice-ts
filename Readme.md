## 🌟 NestJS Kafka Microservice Bus (TypeScript)

### 🎯 Project Vision and Architectural Focus (Ertugrul96)

I developed this project to demonstrate advanced proficiency in building **event-driven microservices** using **NestJS** and **Apache Kafka**. This architecture showcases enterprise-level expertise in highly scalable, decoupled backends.

**Key Goals of the Implementation:**

* **Event Streaming Mastery:** Implementing both a **Kafka Producer** (Event Publisher) and a **Kafka Consumer** (Event Listener) to manage asynchronous communication.
* **Typescript Standard:** Leveraging **NestJS** and **TypeScript** to ensure clean, maintainable code quality across multiple microservices.
* **Enterprise Integration:** Designing the system for compatibility with relational databases like **PostgreSQL/SQL** and high-speed caching layers like **Redis**.

---

### 🛠️ Key Capabilities & Technology Stack

This project uses the modern features of NestJS to solve the core architectural challenges of Node.js:

* **Core Framework:** **NestJS** (Used for dependency injection, modularity, and managing the application lifecycle).
* **Event Broker:** **Apache Kafka** (Showcases mastery of event-driven patterns and pub/sub messaging).
* **Database Strategy:** The decoupled architecture supports relational data persistence (e.g., using **PostgreSQL**) and specialized caching with **Redis**.
* **Philosophy:** Nest provides an application architecture (inspired by Angular) that allows for effortless creation of highly testable, scalable, and loosely coupled applications.

---

### 💻 Setup and Execution

1.  **Clone this repository.**
2.  Install dependencies (`npm install`).
3.  Ensure Kafka is running (e.g., via Docker).
4.  Run the Consumer (Microservice) and the Producer (Client) in separate terminal instances.
